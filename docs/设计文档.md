# WinConsole Manager 设计方案（Python + PyQt6 + pywinpty）

> 目标：实现一个「左侧导航 + 右侧终端」的 Windows 控制台管理工具，用于集中管理多会话、多命令行任务，替代混乱的多标签终端。

---

## 1. 功能目标与使用场景

### 1.1 核心需求

1. 左侧导航列表/树：
   - 展示当前所有会话（Session），包括名称、状态（运行中/已退出）、标签。
   - 支持按「项目」「标签」分组（后续迭代）。

2. 右侧终端区域：
   - 每次只显示一个激活会话的终端。
   - 支持基本输入/输出、历史滚动、简单搜索。

3. 会话管理：
   - 从模板一键创建会话（比如：evoice-wsl、FunASR-demo、ZjExam-dev 等）。
   - 启动、关闭、重命名会话。
   - 为会话添加备注（描述当前任务）。

4. 配置与持久化：
   - 使用 YAML/JSON 存储会话模板（常用命令集合）。
   - 应用退出时保存当前会话信息（用于历史回溯/恢复）。

5. 平台约束：
   - 运行在 Windows 10+。
   - 支持 PowerShell、cmd、WSL 等命令行程序，通过 pywinpty 封装 ConPTY。

---

## 2. 技术选型

- 语言：Python 3.11+
- UI：PyQt6
- 终端后端：pywinpty（内部使用 ConPTY）
- 配置格式：YAML（`PyYAML`）
- 结构设计：模块化，便于后续替换终端控件（比如 WebView + xterm.js）

## 5. 核心数据模型（`models.py`）

```python
from dataclasses import dataclass, field
from enum import Enum, auto
from typing import List, Dict, Optional
import datetime
import uuid


class SessionStatus(Enum):
    STARTING = auto()
    RUNNING = auto()
    EXITED = auto()
    ERROR = auto()


@dataclass
class SessionTemplate:
    id: str
    name: str
    cmd: str
    args: List[str]
    cwd: str
    tags: List[str] = field(default_factory=list)
    env: Dict[str, str] = field(default_factory=dict)


@dataclass
class Session:
    id: str
    name: str
    cmd: str
    args: List[str]
    cwd: str
    tags: List[str] = field(default_factory=list)
    env: Dict[str, str] = field(default_factory=dict)

    status: SessionStatus = SessionStatus.STARTING
    started_at: datetime.datetime = field(default_factory=datetime.datetime.now)
    exited_at: Optional[datetime.datetime] = None
    description: str = ""
    # 后端专用句柄（不序列化）
    backend: "TerminalBackend" = field(default=None, repr=False, compare=False)

    @staticmethod
    def from_template(tpl: SessionTemplate) -> "Session":
        return Session(
            id=str(uuid.uuid4()),
            name=tpl.name,
            cmd=tpl.cmd,
            args=list(tpl.args),
            cwd=tpl.cwd,
            tags=list(tpl.tags),
            env=dict(tpl.env),
        )
```

## 6. Session 管理模块（`session_manager.py`）

### 6.1 职责

- 管理所有 Session 的生命周期：
  
  - 创建/启动 Session（基于模板）。
  
  - 停止 Session。
  
  - 查找当前 Session 列表。

- 作为 UI <-> 后端 的中间层。

### 6.2 接口设计（示例）

```python
from typing import Dict, List, Optional, Callable
from .models import Session, SessionTemplate, SessionStatus
from .terminal_backend import TerminalBackend


class SessionManager:
    def __init__(self, templates: List[SessionTemplate]):
        self.templates: Dict[str, SessionTemplate] = {t.id: t for t in templates}
        self.sessions: Dict[str, Session] = {}

        # UI 回调（可通过 setter 注入）
        self.on_session_added: Optional[Callable[[Session], None]] = None
        self.on_session_updated: Optional[Callable[[Session], None]] = None
        self.on_session_removed: Optional[Callable[[str], None]] = None

    def create_session_from_template(self, template_id: str) -> Session:
        tpl = self.templates[template_id]
        session = Session.from_template(tpl)

        backend = TerminalBackend(
            session_id=session.id,
            cmd=session.cmd,
            args=session.args,
            cwd=session.cwd,
            env=session.env,
        )

        session.backend = backend
        self.sessions[session.id] = session

        # 注册后端事件
        backend.on_started = lambda: self._update_status(session, SessionStatus.RUNNING)
        backend.on_exited = lambda: self._update_status(session, SessionStatus.EXITED)
        backend.on_error = lambda: self._update_status(session, SessionStatus.ERROR, set_exit=True)

        backend.start()  # 启动线程 + 子进程

        if self.on_session_added:
            self.on_session_added(session)

        return session

    def _update_status(self, session: Session, status: SessionStatus, set_exit: bool = False):
        session.status = status
        if set_exit:
            import datetime
            session.exited_at = datetime.datetime.now()
        if self.on_session_updated:
            self.on_session_updated(session)

    def stop_session(self, session_id: str):
        session = self.sessions.get(session_id)
        if not session:
            return
        if session.backend:
            session.backend.stop()
        # 不立刻删除，让 UI 还能显示“已退出”
        if self.on_session_updated:
            self.on_session_updated(session)

    def remove_session(self, session_id: str):
        if session_id in self.sessions:
            session = self.sessions[session_id]
            if session.backend:
                session.backend.stop()
            del self.sessions[session_id]
            if self.on_session_removed:
                self.on_session_removed(session_id)

    def get_sessions(self) -> List[Session]:
        return list(self.sessions.values())
```

## 7. 终端后端封装（`terminal_backend.py`）

> 使用 pywinpty 作为 Windows 下的 PTY 封装，运行在 QThread 中负责读写子进程。

### 7.1 后台线程模型

```python
from PyQt6.QtCore import QThread, pyqtSignal
from typing import Optional, Dict, List
import os

# 注意：下面是示例，具体 API 以 pywinpty 文档为准
import pywinpty  # pip install pywinpty


class TerminalBackend(QThread):
    output_ready = pyqtSignal(str)   # 有新输出时发射
    exited = pyqtSignal(int)         # 进程退出时发射（exit code）

    def __init__(self, session_id: str, cmd: str, args: List[str], cwd: str, env: Dict[str, str]):
        super().__init__()
        self.session_id = session_id
        self.cmd = cmd
        self.args = args
        self.cwd = cwd
        self.env = env or {}
        self._running = True
        self._process: Optional[pywinpty.PtyProcess] = None

        # 对 UI 的事件回调（非 Qt signal，可选）
        self.on_started = None
        self.on_exited = None
        self.on_error = None

    def run(self):
        try:
            full_env = os.environ.copy()
            full_env.update(self.env)

            command = " ".join([self.cmd] + self.args) if self.args else self.cmd

            # 示例：创建 PTY 进程
            self._process = pywinpty.PtyProcess.spawn(
                command,
                cwd=self.cwd or None,
                env=full_env
            )

            if self.on_started:
                self.on_started()

            while self._running:
                try:
                    data = self._process.read(1024)
                except EOFError:
                    break
                if not data:
                    break
                self.output_ready.emit(data)

            exit_code = self._process.exitstatus if self._process else 0
            self.exited.emit(exit_code)
            if self.on_exited:
                self.on_exited()

        except Exception as e:
            if self.on_error:
                self.on_error()
            self.output_ready.emit(f"\n[Backend Error] {e}\n")
        finally:
            self._running = False

    def send_input(self, text: str):
        if self._process:
            # Windows 控制台需要 \r\n
            self._process.write(text)

    def stop(self):
        self._running = False
        if self._process:
            try:
                self._process.close()
            except Exception:
                pass
```

## 8. 终端控件（`terminal_widget.py`）

> 第一版先用 `QPlainTextEdit` 做一个“粗糙终端”：
> 
> - 后台线程把输出 append 到 text edit；
> 
> - 用户输入一行回车后，通过 backend 发到子进程。

后续再换成更专业的终端控件（例如 WebEngine + xterm.js）。

```python
from PyQt6.QtWidgets import QPlainTextEdit
from PyQt6.QtCore import pyqtSignal, Qt
from .terminal_backend import TerminalBackend


class TerminalWidget(QPlainTextEdit):
    """简单终端控件，包装 TerminalBackend"""

    title_changed = pyqtSignal(str)  # 预留：当标题改变时通知外部

    def __init__(self, backend: TerminalBackend, parent=None):
        super().__init__(parent)
        self.backend = backend
        self.setReadOnly(False)
        self.setUndoRedoEnabled(False)
        self.document().setMaximumBlockCount(2000)

        # 当前输入起始位置（防止用户修改历史输出）
        self._input_start_pos = self.document().characterCount() - 1

        # 连接信号
        self.backend.output_ready.connect(self._on_output)
        self.backend.exited.connect(self._on_exited)

        # 启动后台线程
        self.backend.start()

    def _append_text(self, text: str):
        cursor = self.textCursor()
        cursor.movePosition(cursor.MoveOperation.End)
        cursor.insertText(text)
        self.setTextCursor(cursor)
        self._input_start_pos = self.document().characterCount() - 1

    def _on_output(self, data: str):
        self._append_text(data)

    def _on_exited(self, code: int):
        self._append_text(f"\n[Process exited with code {code}]\n")

    def keyPressEvent(self, event):
        # 控制不允许用户回到历史区域编辑
        cursor = self.textCursor()
        if cursor.position() < self._input_start_pos:
            cursor.setPosition(self.document().characterCount() - 1)
            self.setTextCursor(cursor)

        if event.key() in (Qt.Key.Key_Return, Qt.Key.Key_Enter):
            # 提取从 _input_start_pos 到末尾的一行作为输入
            doc = self.document()
            text = doc.toPlainText()
            user_input = text[self._input_start_pos:]
            # 加上换行符写入子进程
            self.backend.send_input(user_input + "\r\n")
            self._append_text("\n")  # 在自己的终端中也换行
            return

        super().keyPressEvent(event)
```

### 9.2 主窗体骨架

```python
from PyQt6.QtWidgets import (
    QMainWindow, QWidget, QSplitter, QListWidget,
    QListWidgetItem, QStackedWidget, QVBoxLayout, QToolBar, QAction, QApplication
)
from PyQt6.QtCore import Qt
from .session_manager import SessionManager
from .terminal_widget import TerminalWidget
from .config_loader import load_session_templates


class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("WinConsole Manager")
        self.resize(1400, 800)

        templates = load_session_templates("config/sessions.yaml")
        self.session_manager = SessionManager(templates)

        # UI 元素
        self.session_list = QListWidget()
        self.terminal_stack = QStackedWidget()

        splitter = QSplitter()
        splitter.addWidget(self.session_list)
        splitter.addWidget(self.terminal_stack)
        splitter.setStretchFactor(0, 0)
        splitter.setStretchFactor(1, 1)

        central = QWidget()
        layout = QVBoxLayout(central)
        layout.addWidget(splitter)
        self.setCentralWidget(central)

        # 工具栏
        toolbar = QToolBar("Main")
        self.addToolBar(toolbar)

        act_new = QAction("新建会话", self)
        act_stop = QAction("停止会话", self)
        toolbar.addAction(act_new)
        toolbar.addAction(act_stop)

        act_new.triggered.connect(self.on_new_session)
        act_stop.triggered.connect(self.on_stop_session)

        # SessionManager 回调绑定
        self.session_manager.on_session_added = self._on_session_added
        self.session_manager.on_session_removed = self._on_session_removed

        # 左侧列表事件
        self.session_list.currentRowChanged.connect(self._on_session_selected)

    def on_new_session(self):
        # 简化：直接用第一个模板，新版可以弹对话框让你选模板
        if not self.session_manager.templates:
            return
        template_id = list(self.session_manager.templates.keys())[0]
        self.session_manager.create_session_from_template(template_id)

    def on_stop_session(self):
        row = self.session_list.currentRow()
        if row < 0:
            return
        item = self.session_list.item(row)
        session_id = item.data(Qt.ItemDataRole.UserRole)
        self.session_manager.stop_session(session_id)

    # SessionManager -> UI
    def _on_session_added(self, session):
        item = QListWidgetItem(session.name)
        item.setData(Qt.ItemDataRole.UserRole, session.id)
        self.session_list.addItem(item)

        # 为该 session 创建 TerminalWidget
        backend = session.backend
        term_widget = TerminalWidget(backend)
        self.terminal_stack.addWidget(term_widget)

        # 默认切换到新会话
        self.session_list.setCurrentItem(item)

    def _on_session_removed(self, session_id: str):
        # 简化：不实现，后续根据需要从 list/stack 删除
        pass

    def _on_session_selected(self, row: int):
        if row < 0:
            return
        self.terminal_stack.setCurrentIndex(row)
```

## 10. 配置加载模块（`config_loader.py`）

```python
import yaml
from typing import List
from .models import SessionTemplate


def load_session_templates(path: str) -> List[SessionTemplate]:
    with open(path, "r", encoding="utf-8") as f:
        data = yaml.safe_load(f) or []
    templates: List[SessionTemplate] = []
    for item in data:
        templates.append(SessionTemplate(
            id=item["id"],
            name=item["name"],
            cmd=item["cmd"],
            args=item.get("args", []) or [],
            cwd=item.get("cwd", ""),
            tags=item.get("tags", []) or [],
            env=item.get("env", {}) or {},
        ))
    return templates
```

## 15. Tab 标签智能命名

- **需求**：窗口左侧导航和上方 Tab 需要根据会话语义自动命名，而不是简单的「Session 1/2/3」。
- **数据入口**：
  - 模板字段 `title_format`（新增，可选），支持占位符：`{name}`、`{tag}`、`{index}`、`{project}`、`{env}`、`{pid}`；
  - 用户创建会话时的覆盖参数（手动输入名称、备注、当前项目）。
- **算法**：
  1. `SessionManager.create_session()` 内新增 `derive_tab_title(template, overrides, runtime_state)`;
  2. 若 `overrides.custom_name` 存在直接返回；
  3. 若模板提供 `title_format`，使用 `format_map` 进行填充；
  4. 否则回退 `{template.name}#{per_template_counter}`;
  5. 若生成过程中出现冲突（同名 Tab），在尾部附加 `-<unique_id>`。
- **实现要点**：
  - 计数器以模板 `id` 为 key；
  - `SessionModel` 增加 `display_name` 字段，UI 层绑定并监听更新；
  - 暴露一个 `rename_session(session_id, new_name)` 接口以便手动调整。
- **测试**：
  - `test_session_manager.py` 覆盖默认命名、多模板序号独立、格式化占位未提供时回退默认、冲突处理等。

## 16. 百炼（Bailian）模型集成

- **目的**：利用百炼模型（如 `qwen-plus`）为 Tab 命名、备注生成、日志摘要提供 AI 支持。
- **配置**：
  - `config/app.yaml` 增加 `bailian.enabled/api_key/model/endpoint`，其中 `api_key` 默认读取 `BAILIAN_API_KEY` 环境变量；
  - 允许为不同环境指定模型（如 `qwen-plus`, `qwen-turbo`）。
- **封装**：
  - 在 `utils.py` 实现 `BailianClient`（简单 POST 请求封装），包含重试、超时（默认 5s）与异常分类；
  - `SessionManager` 中注入可选的 `BailianClient`，命名算法可在本地规则失败时请求模型返回建议。
- **调用流程**：
  1. 组装 Prompt（模板名称、标签、备注等）；
  2. 如果 `enabled` 且 `api_key` 有效，调用模型；否则直接回退本地逻辑；
  3. 对回复做清洗（截断过长字符、移除换行），再写入 `display_name` 或 `remarks`；
  4. 记录日志（成功/失败）供调试。
- **安全要求**：
  - 禁止把真实路径、凭证写入 Prompt，可用占位符；
  - Key 不得入库，使用 `app.yaml` + 环境变量；
  - 提供开关（UI 或配置）以在离线环境禁用。
- **测试**：
  - 使用 `responses` 或手工 mock HTTP 调度，验证启用/禁用、失败回退、Prompt 构造。
