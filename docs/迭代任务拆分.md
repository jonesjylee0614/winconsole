# WinConsole Manager 迭代拆分

依据当前缺口与优化建议，总结后续可执行的迭代任务如下：

## 迭代 A：Shell 生命周期与 pywinpty 基础 ✅
- 安装/检测 `pywinpty`，缺失时阻止启动并给出明确提示。
- Shell 切换（PowerShell/CMD/WSL）时保留会话元数据，tab 重新激活时应显示最近使用的 shell。
- 每个会话维护“重启当前 shell”的能力，提供按钮或命令来重新拉起 backend。

## 迭代 B：WSL 初始化与命令体验 ✅
- 启动 WSL 时自动附加 `bash -lc 'source ~/.bashrc'` 等 hook 以启用用户 alias（例如 `ll`）。
- Action 按钮执行命令时要反馈状态（执行中/成功/失败），并在终端插入提示。
- Hint 区域加入“如何切换 shell”的提示，帮助用户发现 `wsl`/`cmd` 等快捷指令。

## 迭代 C：多 PTY / 多 shell 并行
- 在同一个 tab 中支持多个 shell 实例，共享输出历史但可随时切换回去。
- Header 提供 shell 列表或标签，允许关闭/重启某个 shell 实例。

## 迭代 D：配置与 UX 补完
- UI 内的描述/备注编辑结果需要持久化（写回配置或本地仓库）。
- Template Actions 执行后自动滚动、聚焦、展示“下一步”提示。
- Tag 过滤、搜索、空状态提示等细节与《优化建议》完全对齐。

## 迭代 E：自动化与文档
- 为配置扩展、session manager、shell 状态机补充 pytest 覆盖。
- 更新文档：依赖安装（PyQt6/pywinpty/pytest）、WSL alias FAQ、常见错误处理。
- 提供 `requirements-dev.txt` 或 Makefile，便于一键安装开发依赖和运行测试。
